# Portafolio académico — Paulo Escandón

Sitio estático en HTML, CSS y JavaScript, preparado para publicar con GitHub Pages.

## Publicación rápida con GitHub Pages

1. Inicia sesión en https://github.com/ y crea un repositorio nuevo llamado `paulo-escandon`.
2. Puedes marcarlo como **Public**. No necesitas agregar README porque ya viene en esta carpeta.
3. Descomprime este ZIP en tu computadora.
4. Dentro del repositorio, selecciona **Add file → Upload files** y sube `index.html`, `README.md` y la carpeta `assets` completa (incluye el CV PDF).
5. Pulsa **Commit changes**.
6. Abre **Settings → Pages**.
7. En **Build and deployment**, elige **Deploy from a branch**.
8. Selecciona la rama `main` y la carpeta `/(root)`, y pulsa **Save**.
9. Espera unos minutos. GitHub mostrará la dirección de tu sitio, normalmente:
   `https://TU-USUARIO.github.io/paulo-escandon/`

## Personalización recomendada antes de publicar

- Revisa el número de años y publicaciones mostrado en las tarjetas iniciales; son indicadores visuales aproximados y están señalados en la web para que los ajustes.
- Comprueba los DOI y los enlaces de cada publicación.
- Si quieres una fotografía, reemplaza el círculo con las iniciales “PE” por una foto profesional.
- Confirma que deseas publicar los datos de contacto. El sitio incluye el correo y los enlaces profesionales que aparecen en el CV.
- El CV descargable está en `assets/CV_Paulo_Escandon.pdf`.
